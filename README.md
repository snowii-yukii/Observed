# OBSERVED

An interactive, animated "Eye" component built with React. The eye follows the user's cursor around the screen, blinks periodically, and closes when the cursor leaves the window or the tab becomes hidden.

## Features

- **Cursor Tracking**: The iris follows the mouse cursor smoothly as it moves across the screen.
- **Auto-blinking**: The eye will blink at random intervals.
- **Mouse Out Detection**: The eye closes when the mouse leaves the browser window.
- **Tab Visibility**: The eye closes when you switch tabs or minimize the browser.

## Technologies Used

- React (Vite)
- CSS for styling, transitions, and layout
